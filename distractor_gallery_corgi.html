Distractor gallery: Corgi

The test set for the corgi property search: 20 real corgis, 20 different-class distractors, and 20 perturbed corgis. Each instance is shown with the image and the one-sentence description it was judged by. A property set should keep every real corgi and reject every other instance.

How the instances and descriptions were made

Real corgis: v01, v13, v14, v15 of the first 20 drawn at random (random.Random(0)) from the 100 ImageNet validation images of Pembroke (263) and Cardigan (264), kept because each shows one whole corgi standing; v21-v36 chosen by eye from the other 80 for the same reason (the first set is valid.v1.json). Each photo described by gpt-5.6-sol (reasoning none), from the photo:

You are given a photo of a corgi. Describe how this corgi looks in one sentence that begins "A corgi with": mainly the shapes of its body and its parts and their sizes next to one another, and in a few words its colors. Describe only the corgi as it is seen in the photo, not its pose or the background, and leave out any part that cannot be seen.
Return JSON only: {"description": "A corgi with ..."}

Different class: named by gpt-5.6-sol from the class name alone, then edited by hand; each described by gpt-5.6-sol (reasoning none), from its name (user message “Kind of thing: <name>”):

You are given a kind of thing. Describe how a typical one looks in one sentence that begins with its name and "with", as in "A mug with ...": mainly the shapes of its body and its parts and their sizes next to one another, and in a few words its colors.
Return JSON only: {"description": "<the sentence>"}

Perturbed: named the same way; each described from its name (user message “Changed corgi: <name>”), some descriptions then edited by hand:

You are given a changed corgi: a typical corgi with one thing about how it looks changed, named by that change. Describe how it looks in one sentence that begins "A corgi with": first the change, stated exactly (for a number, say how many; for a size, say how big next to another part), then mainly the shapes of its other parts and their sizes next to one another, and in a few words its colors.
Return JSON only: {"description": "A corgi with ..."}

Images of the distractors, from each description, by gemini-2.5-flash-image; a few perturbed ones drawn again by Nano Banana 2.1 where the first image did not show the change:

A realistic photo, with the whole of it in view: {description}
