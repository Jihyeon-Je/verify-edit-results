Which is better?

Thank you for helping with this study! You will see 40 pairs of objects, one pair per page. It should take about 10 minutes.

What to do

Each page names a class at the top, such as "a pelican". Below it are two versions of an object of that class, A and B, each made by a computer program. Choose the one that is a better example of the class: the one whose parts, shapes, colors and arrangement better match what an object of that class looks like.

  • A A is better
  • B B is better
  • S Same: neither is better than the other

Some pairs are flat 2D drawings. Others are 3D models shown from two viewpoints side by side: both views in a box are the same object. Judge the object, not the drawing style or the lighting, which are the same for A and B.
